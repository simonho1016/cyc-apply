👥 帳號及權限管理

四層權限：admin（所有權限）＞ 管理級（管理夾萬同工所有功能 ＋ 夾萬「現存→代管」過錢）＞ 管理夾萬同工（支錢、舍友存入、製作及下載文件；要指派管理邊個社嘅夾萬）＞ 普通同工（支錢、檢視文件）。所有 @sbccyc.org.hk 網域登入嘅同事預設係「普通同工」。新同事第一次登入後會出現喺「未登記同事」區，由 admin 補返姓名同職級。admin 可以新增、修改、刪除任何帳號，包括新增其他 admin；ho.ml／ho.lh 係永久 admin，唔可以改。設定喺同事下次登入時生效。

🔭 模擬檢視

用其他角色嘅視角睇系統實際畫面，方便檢查權限設定。模擬只影響你呢個瀏覽器分頁；期間畫面頂部會有黃色提示橫額，撳「取消模擬」即還原。注意：模擬期間嘅操作（支錢、存入等）會真實生效；簽名檔喺模擬時唔會自動解鎖。

🔏 簽名密碼

只有何文諾、何樂軒有電子簽名圖。同事喺支錢頁揀佢哋做「支款人」時，要輸入呢度嘅密碼先用到對應簽名檔（本人用 Google 登入揀自己就唔使）。其他同事冇簽名檔，支錢時即場簽署，唔使密碼。同事姓名同職級喺上面「👥 帳號及權限管理」度改。

🗂️ 電子存檔（Supabase Storage）

「電子存檔」會將 PDF 上傳到 Supabase Storage 嘅 apply-archive bucket，按 zhong／xiao（社別）→ 舍友編號 → 檔案 分類（Supabase 唔支援中文路徑，所以用英文編碼）；本機同時會下載一份做後備，本機檔名維持「舍友編號_日期」。免費計劃（1 GB）大約可儲存 2,500–5,000 張 PDF。

Bucket 未開通時，存檔仍會儲存雲端記錄同本機下載 PDF，只係冇雲端檔案；記錄頁嘅「下載 PDF」掣會喺該記錄有雲端檔案時先出現。

🚀 轉正式版本

而家係測試版，所有數據只供測試。正式上線時喺度清除測試數據重新開始。此操作唔可以還原。舍友名單（包括已退出標記）、職員權限設定同簽名檔會保留；執行後會記低「轉正式」時間同經手人。

✏️ 修訂舍友

現存未歸 0 嘅舍友唔可以改編號（只可以改姓名）；要改編號請先將結存歸 0，或者用「轉社」搬編號。

🔀 舍友轉社

確認後：舍友會即刻轉社；結存（如有）會由舊社代管現金自動搬去新社代管現金，並記入流水賬（月結會顯示轉出／轉入）。舊編號嘅歷史支錢記錄會保留唔變。
